# Amazon Fresh Database Design & Analytics

## Executive Summary
Designed and implemented a relational database system for an online grocery platform using structured data modeling and SQL analytics. The project focused on building a normalized schema and extracting business insights from transactional data.

## Business Objectives
- Design an efficient relational database
- Apply normalization principles (up to 3NF)
- Ensure data integrity and reduced redundancy
- Extract meaningful business insights using SQL queries

## Dataset Overview
- 6 relational tables
- Each table: ~7,000–10,000 records
- Entities: Customers, Orders, Products, Suppliers, Categories, Order Details

## Tools & Technologies
- SQL – Database creation and analytical querying
- ER Diagram – Entity relationship modeling
- Data Normalization – 3NF implementation

## Database Design Approach
- Identified primary and foreign keys
- Defined relationships between entities
- Applied normalization to eliminate redundancy
- Ensured referential integrity

## Analytical Queries Performed
- Top customers by revenue
- High-value order identification
- Supplier performance analysis
- Category-wise sales distribution
- Order frequency analysis

## Key Insights
- Revenue concentrated among repeat customers
- Certain product categories showed higher transaction frequency
- Supplier dependency observed in specific categories

## Strategic Recommendations
- Strengthen supplier diversification
- Introduce loyalty incentives for repeat customers
- Optimize category-level inventory planning
